# Regional Panchang — India-first Hindu Calendar

A state-adaptive Hindu Panchang and calendar platform built around deterministic Swiss Ephemeris calculations and regional calendar rules.

## Product principles

- **Astronomy first:** astronomical calculations are deterministic; AI must never decide festival dates.
- **Regional by design:** state/UT selection changes calendar system, month naming, muhurat system, language fallback, visual style and priority fields.
- **Mobile first:** Material-inspired drawer navigation, bottom navigation, installable PWA shell and Capacitor Android/iOS configuration.
- **Trust:** festival responses expose the calculation engine and rule type.

## Current capabilities

- Swiss Ephemeris / Lahiri sidereal calculations
- Location-aware sunrise/sunset
- Tithi, Nakshatra, Yoga, Karana and Vaar
- Rahu Kalam and Abhijit Muhurat
- Regional Choghadiya / Gowri Panchangam
- Astronomical solar-ingress festivals such as Makar Sankranti/Pongal/Vishu
- Sunrise-tithi + lunar-month festival resolver
- Amanta/Purnimanta festival rules
- 36 state/UT configurations
- Regional solar month names for Tamil and Malayalam modes
- Festival markers in the monthly calendar
- Font-size accessibility controls
- PWA manifest, offline shell and install prompt
- Capacitor 8 Android/iOS shell configuration
- JSON storage, optional Redis, optional PostgreSQL

## Run

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Open `http://localhost:8000` and `http://localhost:8000/docs`.

## APIs

- `GET /api/v1/health`
- `GET /api/v1/states`
- `GET /api/v1/panchang`
- `GET /api/v1/rashifal`
- `GET /api/v1/festivals`
- `GET /api/v1/lunar-month`
- `GET /api/v1/calendar/month`

## Mobile

```bash
cd frontend
npm install
npm run cap:add:android
npm run cap:add:ios
npm run cap:sync
```

Native platform folders are generated by Capacitor in the build environment. The repository contains the app configuration and CI validation rather than committing generated platform directories.

## Accuracy release gate

The next mandatory production gate is a **2025–2030 reference-date validation corpus** covering major festivals and regional variants. No launch claim of authoritative dates should be made until that corpus is reconciled against trusted regional Panchang references.

See [`docs/LAUNCH_PLAN.md`](docs/LAUNCH_PLAN.md) for the roadmap and competitive product strategy.
